# Mac에서 실행하는 방법

[테스트 환경](../README.md#requirements)을 먼저 확인하세요. 현재 설치 파일은 배포되지 않아 Xcode에서 빌드해야 합니다.

## 앱 빌드하기

1. 저장소에서 **Code → Download ZIP**을 선택하고 압축을 풉니다.
2. Xcode에서 `KakaoBanner.xcodeproj`를 엽니다.
3. **KakaoBanner**와 **BannerProxy** 타깃의 **Signing & Capabilities**에서 네트워크 확장 권한으로 서명할 수 있는 본인의 팀을 선택합니다. macOS 앱과 확장에 맞는 프로비저닝이 필요합니다.
4. **KakaoBanner** 스킴을 빌드합니다. Xcode의 **Products**에서 빌드된 앱을 Finder로 열고, **응용 프로그램** 폴더에 복사한 뒤 그 복사본을 실행합니다.

## 첫 실행에서 권한 설정하기

1. **확장 설정 시작**을 누릅니다. macOS에서 스튜디오의 네트워크 확장 승인을 요청하면 허용합니다.
2. **인증서 설정**을 누르고 macOS 확인을 완료합니다. 스튜디오는 이 인증서를 사용해 카카오톡 배너 응답을 이 Mac에서 교체합니다.
3. 설정을 다시 열려면 **네트워크 및 인증서 → 설치 가이드 열기**를 선택합니다.

설정을 마쳤다면 [배너 바꾸기](../README.md#배너-바꾸기)를 따라 적용하세요.
